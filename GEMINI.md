# Diretrizes do Projeto

## Fluxo de Versionamento Git
- **Sempre realizar commit e push para o repositório remoto no GitHub (`origin main`)** após implementar ou alterar qualquer funcionalidade concluída com sucesso.
- Mensagens de commit devem seguir o padrão Conventional Commits (ex: `feat: ...`, `fix: ...`, `docs: ...`).
